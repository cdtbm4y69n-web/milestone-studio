# Milestone Studio Vercel Site

This is a Vercel-ready React/Vite project.

## Files included

- package.json
- index.html
- src/main.tsx
- src/App.tsx

## What to change later

In `src/App.tsx`, replace the `heroImageUrl` value with your final sharpened product image URL.

## Vercel settings

Framework Preset: Vite  
Build Command: npm run build  
Output Directory: dist  
Install Command: npm install
